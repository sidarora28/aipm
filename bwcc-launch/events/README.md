# Events — BWCC Cohort 003 launch series

4 live-build masterclasses across the 4 weekends before Cohort 003 starts (Jul 19).

Each event is a 90-min live build masterclass. The pattern:
- Pitch pre-announced at minute 0 (disarms "sales coming" exit)
- 3 milestones / concepts per event, each ~25-30 min
- 3 giveaways dropped at min 22 / 50 / 75 (live-only, packaged as starter kits)
- 60-sec close + live-only cohort code at min 88
- Open Q&A from min 90 onward

## Cross-event retention pattern (applies to all 4)

- **Pitch pre-announcement at min 0** — kills the "ugh sales coming" exit reflex
- **Stacked giveaways throughout** — multiple drop-moments mean each upcoming moment is a reason to stay
- **Cohort references woven in** — 30 sec at the end of each milestone, not a separate 5-min pitch
- **Live-only cohort code at min 88** — only people watching live get it
- **1:1 Loom bonus for night-of buyers** — last-minute incentive

## Cross-event production pattern (applies to all 4)

Each event becomes:
- 1× long-form YouTube (90 min lightly trimmed)
- 3× milestone YouTube videos (~25-30 min each)
- 8-12 Reels / YouTube Shorts via Opus Clip
- LinkedIn native + Twitter video clips

Four events × ~15 content pieces each = 60+ content artifacts for the YouTube channel and social feeds over 30 days, without filming anything new.

## Cross-event ad pattern (applies to all 4)

Per event:
- 60-sec promo video creative
- $50/day × 7 days = $350 spend
- 2 creative variants, kill loser by day 2
- Audiences: lookalike of Beehiiv list + AI/builder interests + site retargeting

Total ad spend across 4 events: ~$1,400.
