## Running an event

Emails per session, all to `seg_44d4cd95`:

1. **Thu** — educational email, teaches the session's idea in full
2. **Fri AM** — second educational email, the harder half
3. **Fri 16:30 UTC** — 24-hour reminder
4. **Sat 15:30 UTC** — one hour to go
5. **Sat 16:30 UTC** — we're live
6. **Sat 17:30 UTC** — mid-event, carries the discount code

The two educational emails do the selling by teaching. The reminders are logistics only.
Voice rules for all of them live in `secondbrain/` — do not write these from scratch
without reading Sid's published newsletter first.
